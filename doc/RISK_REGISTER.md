# Life — Engineering & Governance Risk Register
Audit date: 2026-10-15 (Asia/Taipei). Scope: `tommylin15/life_assistant` main tree, selected source/workflows, GitHub Actions and Drive `life_assistantGPT` hierarchy. **Risk ≠ confirmed incident**. Ranking is a prioritization, not a security scan certification. Updates belong here, not duplicated in five status documents.

## Non-goals of this cleanup
- No production data deletion, migration rollback, IAM changes, secret rotation, runtime deployment, or reactivation of retired collectors.
- No invented costs, row counts, or user-level QA outcomes. `PASS` only for the specific evidence linked above.
- Prior stable audits stay in Git history, and Drive exploration 01–05 remain the authority for discovery strategy.
